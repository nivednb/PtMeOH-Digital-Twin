# REQUIRES STUDENT MANUAL CHECK

These checks must be completed by a person; automated checks do not establish physical input usability.

1. Launch PtMeOH-DigitalTwin.exe from the complete player folder.
2. Check the first-launch tutorial. If previously completed on this computer, use HELP > START TUTORIAL.
3. Test NEXT, PREVIOUS and SKIP, then replay through HELP.
4. Inspect OVERVIEW and PLANT PROCESS; move through every process stage.
5. Orbit with mouse drag, pan with Shift-drag and zoom with the wheel.
6. Change reactor/process controls and confirm displayed values respond.
7. Open ANALYTICS and select all five OFAT studies; confirm each graph has data and live control settings are preserved.
8. Export CSV, locate the saved file and inspect its current-state values.
9. Exercise warnings and storage/tank trip and reset behaviour.
10. Check text, buttons, captions and graphs for overlap at the normal display resolution and scaling.
11. Close and relaunch; confirm normal startup and tutorial-completion persistence.

Record any failed step and the display resolution before submitting. Confirm required university details, contribution statements and asset permissions in the accompanying report.
